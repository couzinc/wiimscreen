Install from this page

You flash the Tab5 over USB one time. After that, the Tab5 updates itself over Wi-Fi from GitHub.

  1. Use Chrome or Edge on a computer. Connect the Tab5 with a USB-C data cable.
  2. Push the power button one time to turn on the Tab5. Then push and hold it until the green LED flashes (download mode).
  3. Click Install and select the port of the Tab5. When the browser asks, leave Erase device off: your settings and favorites stay.
  4. When the install is complete, push the power button. Scan the QR code on the screen with your phone to set up Wi-Fi and your WiiM.

wiimscreen {{VERSION}} for the M5Stack Tab5

One file, written at address 0x0. The browser does everything: no software to install.

This browser cannot talk to USB devices. Open this page in Chrome or Edge on a computer. The install needs a secure page (https).

Prefer a tool? Download wiim-remote-tab5.bin and write it at 0x0 with ESPWebTool or esptool --chip esp32p4 write-flash 0x0 wiim-remote-tab5.bin.

Windows app: wiimscreen-windows-x64.zip on the release page.

What it does

Everything goes through your WiiM on your own network. The WiiM plays Qobuz and Deezer with its own login.

Now playing

Large album art, title, artist, source and quality (16 bits · 44.1 kHz). The colors follow the cover. Touch the bar to seek.

Tiles and Library

WiiM presets and the albums you save with the heart. Rate them with 1 to 5 stars, pin them, filter them in the Library.

Qobuz

Search tracks, open your Qobuz favorites, Play all or Shuffle. The WiiM does the search with its own account.

Deezer

Search the catalog, keep Flow as a tile, play the favorites of a public profile.

Ambient view

After a minute, or with one touch: a full-screen cover that you can read from across the room.

Safe updates

New versions install from GitHub on the device. If one does not start, the Tab5 goes back to the previous one.

How it works

Only the local interfaces of the WiiM. Some are not documented by WiiM, so a WiiM firmware update can change them.

HTTP API

Status, track, volume, presets and commands, over HTTPS. The Tab5 pins the WiiM's certificate on first contact.

UPnP play queues

The service the WiiM Home app uses. It plays albums, playlists, favorites and search results.

Nothing in the cloud

No account and no password on the device. Only album art, searches and the update check leave your network.
